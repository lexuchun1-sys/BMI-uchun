# BMI Calculator - Uchun

A modern, user-friendly Body Mass Index (BMI) calculator web application built with HTML, CSS, and JavaScript.

## 🌟 Features

- **Easy to Use**: Simple and intuitive interface
- **Real-time Calculation**: Instant BMI results with category classification
- **Visual Feedback**: Color-coded results based on BMI categories
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Input Validation**: Ensures accurate calculations with proper error handling
- **Keyboard Support**: Press Enter to calculate
- **BMI Reference Chart**: Built-in guide showing all BMI categories

## 📊 BMI Categories

| Category | BMI Range | Description |
|----------|-----------|-------------|
| Underweight | < 18.5 | May need to gain weight |
| Normal Weight | 18.5 - 24.9 | Healthy weight range |
| Overweight | 25 - 29.9 | May need to lose weight |
| Obese | ≥ 30 | Should consult healthcare provider |

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- No installation required!

### Usage

1. **Clone the repository**:
   ```bash
   git clone https://github.com/lexuchun1-sys/BMI-uchun.git
   ```

2. **Open the application**:
   - Navigate to the project folder
   - Open `index.html` in your web browser
   - Or simply double-click the `index.html` file

3. **Calculate your BMI**:
   - Enter your weight in kilograms (kg)
   - Enter your height in centimeters (cm)
   - Click "Calculate BMI" or press Enter
   - View your results with category and health advice

4. **Reset**:
   - Click the "Reset" button to clear all inputs and start over

## 🧮 BMI Calculation

BMI is calculated using the following formula:

```
BMI = weight (kg) / [height (m)]²
```

Where:
- Weight is measured in kilograms (kg)
- Height is measured in meters (m)
